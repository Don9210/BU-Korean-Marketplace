# bu-market · BU 한인 중고거래

BU 이메일(bu.edu) 인증을 거친 학생끼리만 거래하는, BU 한인 유학생용 캠퍼스 중고거래 모바일 웹앱입니다.

**배포 링크:** https://bu-korean-marketplace.vercel.app · **팀:** BU LIKELION 6기 — 신동준 · 이동원 · 이준성

## 왜 만드나

BU 한인 유학생은 매 학기 이사·졸업 때 가구와 교재를 사고팔지만, 카톡 단톡방과 페이스북 그룹에 글이 흩어지고 상대가 누구인지 확인할 방법이 없습니다. bu.edu 인증으로 "같은 학교 학생"만 모이는 작은 장터를 만듭니다.

## MVP 기능 (6개)

| # | 기능 |
|---|---|
| 1 | bu.edu 이메일 인증 (6자리 코드) |
| 2 | 물건 등록·수정·삭제 (사진 1~3장) |
| 3 | 목록 & 검색/필터 |
| 4 | 상세 페이지 + 비밀댓글 (+ 이메일 알림) |
| 5 | 거래 상태 & 완료 확인 |
| 6 | 평점/리뷰 |

만들지 않는 것: 실시간 채팅, 결제, 배송, 지도, 푸시 알림. 자세한 범위는 팀 규칙서 참고.

## 기술 스택

| 역할 | 도구 | 쉽게 말하면 |
|---|---|---|
| 화면 | Vite + React + TypeScript + Tailwind CSS | 폰에서 보이는 웹 화면 |
| 로그인·DB·사진 저장 | Supabase | 서버 대신 쓰는 서비스 |
| 메일 발송 | Resend | 인증 코드·댓글 알림 메일 |
| 배포 | Vercel | 링크로 열리게 올려두는 곳 |
| 개발 도구 | Claude Code | AI와 같이 코딩 |

## 폴더 구조

```
bu-market/
├─ AGENTS.md          AI 작업 지시문 (AI가 가장 먼저 읽음)
├─ PROMPTS.md         AI에게 보낸 주요 프롬프트 기록
├─ .env.example       환경변수 양식 (진짜 키는 .env에만, GitHub에 안 올림)
├─ supabase/
│   ├─ schema.sql     DB 테이블·규칙(RLS)·trigger
│   └─ functions/     댓글 알림 메일 (Edge Function)
└─ src/
    ├─ pages/         화면 7개
    ├─ components/    공용 부품 (카드, 버튼 등)
    └─ lib/           Supabase 연결
```

## 내 컴퓨터에서 실행하기

1. 저장소 복사: Claude Code에서 "github.com/Don9210/BU-Korean-Marketplace 복사해와" (또는 `git clone`)
2. `.env.example`을 복사해서 `.env` 만들기 → 두 줄 채우기 (값은 동원에게 직접 받기)
3. Claude Code에서 "개발 서버 켜줘" (또는 `npm install` → `npm run dev`)
4. 브라우저에서 `http://localhost:5173`

**기능 1 인증 설정:** [Supabase·6자리 코드 메일 설정과 BU 계정 2개 테스트](docs/auth-setup.md).
로그인·닉네임 설정·보호된 화면 이동은 구현되어 있으며, 실제 메일 발송은 팀 Supabase 설정 후 확인해야 합니다.

**기능 2 등록·수정·삭제:** [사진 저장소 설정과 본인 글 관리 테스트](docs/listings-setup.md).
`글쓰기`에서 등록하고 `내 활동 → 내 판매 글`에서 수정·삭제합니다.

## 팀 작업 규칙

- **자기 기능 파일은 자유롭게, 공유 파일은 단톡에 한 줄.** 각자 맡은 화면·기능은 동시에 작업해도 된다. 라우터(`App.tsx`), `package.json`, `supabase/schema.sql`, 공용 부품(`components/`)처럼 셋이 다 건드리는 파일을 고칠 땐 단톡에 "라우터에 상세 페이지 추가함, pull 해" 한 줄.
- **작업 시작 전 pull, 끝나면 push.** 작게 자주. 하루 1회 이상 push, 3일 이상 쌓아두지 않기. 충돌(conflict)이 나면 AI에게 "양쪽 다 살려줘".
- **새 기능은 앞 기능이 통과한 뒤.** 실제 bu.edu 계정 2개로 테스트 통과 → 다음 기능.
- **비밀 값은 `.env`에만.** 코드·커밋·단톡에 키 올리지 않기.
- **프롬프트는 `PROMPTS.md`에 기록.** 최종 결과물 요건.
- **코드 프리즈: 발표 3일 전.** 그 뒤로는 버그 수정만.
- 매 세션 첫 메시지는 `AGENTS.md` 내용 (Claude Code는 자동으로 읽음).
